# Алгоритм Дейкстри

**Алгоритм Дейкстри** знаходить найкоротші шляхи у графі з **невід'ємними** вагами ребер від
однієї (стартової) вершини до **всіх** інших. Уявіть карту міст і доріг різної довжини: стоячи
в місті `A`, ви хочете дізнатися найкоротшу відстань до кожного іншого міста.

## 1. Кроки алгоритму

1. **Ініціалізація.** Відстань до старту = `0`, до всіх інших — `∞` (поки не знаємо, як
   дістатися). Жодна вершина ще не «перевірена».
2. **Обробка вершин.** Обираємо непройдену вершину з **найменшою** відстанню. Для кожного її
   сусіда пробуємо **послабити** (relax): якщо `відстань_до_поточної + вага_ребра` менша за
   відому відстань до сусіда — оновлюємо її. Поточну вершину позначаємо перевіреною.
3. **Завершення.** Коли всі досяжні вершини перевірено — відстані остаточні.

## 2. Чому це працює (жадібність)

Оскільки ваги невід'ємні, вершина з найменшою поточною відстанню вже не може стати ближчою —
жоден інший шлях через ще не опрацьовані вершини не буде коротшим. Тому її відстань можна
зафіксувати назавжди. Саме на цьому й тримається жадібний вибір мінімуму.

## 3. Приклад покроково

Граф із 5 вершин і зважених доріг:

```python
graph = {
    'A': {'B': 5, 'C': 10},
    'B': {'A': 5, 'D': 3},
    'C': {'A': 10, 'D': 2},
    'D': {'B': 3, 'C': 2, 'E': 4},
    'E': {'D': 4},
}
```

Зручно вести таблицю «Вершина · Відстань · Перевірено». Початковий стан і кроки від `A`:

| Крок | A | B | C | D | E | Обрано |
|------|---|---|---|---|---|--------|
| старт | 0 | ∞ | ∞ | ∞ | ∞ | — |
| 1 | 0 | **5** | **10** | ∞ | ∞ | A |
| 2 | 0 | 5 | 10 | **8** | ∞ | B |
| 3 | 0 | 5 | 10 | 8 | **12** | D |
| 4 | 0 | 5 | 10 | 8 | 12 | C |
| 5 | 0 | 5 | 10 | 8 | 12 | E |

Результат — найкоротші відстані від `A`: `{A: 0, B: 5, C: 10, D: 8, E: 12}`. Шлях до `E`:
`A → B → D → E` довжиною `12`. Зверніть увагу на крок 3: через `D` до `C` виходить `8 + 2 = 10`
— не коротше за пряме `A–C = 10`, тож відстань до `C` не змінюється.

## 4. Реалізація

Найпростіший варіант — лінійний пошук вершини з найменшою відстанню серед непройдених:

```python {6,9,10}
def dijkstra(graph, start):
    dist = {v: float('inf') for v in graph}
    dist[start] = 0
    unvisited = set(graph)
    while unvisited:
        u = min(unvisited, key=lambda v: dist[v])   # найменша dist
        if dist[u] == float('inf'):
            break                                    # решта недосяжна
        for v, w in graph[u].items():
            if dist[u] + w < dist[v]:                # послаблення
                dist[v] = dist[u] + w
        unvisited.remove(u)
    return dist
```

## 5. Складність

- Лінійний вибір мінімуму на кожному кроці дає **`O(V²)`** — наочно й достатньо для невеликих
  графів.
- З **чергою з пріоритетами** (двійкова купа) вибір мінімуму коштує `O(log V)`, і складність
  падає до `O((V + E) · log V)` — стандартний варіант для великих розріджених графів.

## 6. Важливе застереження

Дейкстра **обходить** граф, але це **не алгоритм обходу**: його мета — оптимізація шляху, а не
просто відвідати всі вершини. Він є розширеним поєднанням ідей пошуку в глибину та в ширину.
Головне обмеження: ваги мають бути **невід'ємними** — для від'ємних ребер потрібен інший
алгоритм (наприклад, Беллмана–Форда).
