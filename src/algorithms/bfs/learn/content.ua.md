# Пошук у ширину (BFS)

**Обхід графа** — фундаментальний алгоритмічний процес: відвідати всі вершини графа,
виконуючи певну дію для кожної. Пошук у ширину (BFS, *Breadth-First Search*) — одна з
двох базових стратегій обходу (друга — пошук у глибину, DFS). BFS відвідує вершини
**шарами**: спершу всіх сусідів старту, потім сусідів цих сусідів — рівень за рівнем,
віддаляючись від початкової вершини.

## 1. Ідея

BFS починається з обраної вершини й відвідує **всі сусідні вершини на поточному рівні**,
перш ніж перейти до наступного рівня. Щоб дотриматися такого порядку, потрібна структура
«перший прийшов — перший вийшов»: **черга** (FIFO).

- Додаємо вершини в **кінець** черги.
- Беремо на обробку з **початку** черги.

Так вершини, додані раніше (ближчі до старту), опрацьовуються першими — і обхід природно
розходиться «колами» від початкової вершини.

## 2. Черга та множина відвіданих

BFS тримає дві структури:

- `queue` — черга вершин, які чекають на обробку;
- `visited` — множина вже відвіданих вершин, щоб не зайти в нескінченний цикл на
  циклічному графі.

Вершину позначаємо відвіданою, коли **знімаємо** її з черги. Якщо її вже відвідали раніше
(потрапила в чергу двічі) — просто пропускаємо.

## 3. Реалізація

```python {6,11}
from collections import deque

def bfs(graph, start):
    visited = set()
    queue = deque([start])             # фронтир — черга (FIFO)
    while queue:
        v = queue.popleft()            # знімаємо з ПОЧАТКУ
        if v not in visited:
            visit(v)                   # відвідуємо вершину
            visited.add(v)
            for x in neighbors(v):     # сусідів — у кінець черги
                if x not in visited:
                    queue.append(x)
```

Ключові рядки — `popleft()` (беремо з початку, FIFO) і `append()` (додаємо в кінець).
Саме вони задають «ширину» обходу.

## 4. Приклад покроково

Розглянемо граф у вигляді списку суміжності:

```python
graph = {
    'A': ['B', 'C'],
    'B': ['A', 'D', 'E'],
    'C': ['A', 'F'],
    'D': ['B'],
    'E': ['B', 'F'],
    'F': ['C', 'E'],
}
```

BFS зі старту `A`:

1. Знімаємо `A`, відвідуємо → у чергу `B, C`.
2. Знімаємо `B`, відвідуємо → у чергу `D, E`.
3. Знімаємо `C`, відвідуємо → у чергу `F`.
4. Знімаємо `D`, `E`, `F` — усі сусіди вже відвідані.

Порядок відвідування: **A B C D E F** — спочатку рівень 0 (`A`), потім рівень 1 (`B, C`),
потім рівень 2 (`D, E, F`).

## 5. BFS і найкоротший шлях

Головна перевага BFS: у **незваженому** графі він знаходить найкоротший шлях (за кількістю
ребер) від старту до будь-якої вершини. Оскільки обхід іде рівнями, вершину вперше досягаємо
саме найкоротшим маршрутом. Тому BFS — природний вибір для задач «найменша кількість кроків»:
маршрутизація, ігри-головоломки, соціальні графи («рукостискання»).

## 6. Складність

- **Час** — `O(V + E)`: кожну вершину знімаємо з черги один раз, кожне ребро оглядаємо
  (у неорієнтованому графі — двічі, з обох кінців).
- **Пам'ять** — `O(V)`: у найгіршому разі в черзі опиняється більшість вершин одного рівня.

## 7. BFS проти DFS

BFS і DFS оглядають той самий граф, але в різному порядку: BFS — «вшир» (рівнями), DFS —
«вглиб» (до кінця гілки, потім назад). BFS економніший для найкоротшого шляху, але тримає в
пам'яті цілий рівень; DFS використовує менше пам'яті, та не гарантує найкоротшого маршруту.
Вибір залежить від задачі.
